# Los Santos Fire Department — GTA SAMP

Sitio web estático gratuito.

## Publicarlo gratis con GitHub Pages
1. Crea una cuenta en GitHub.
2. Crea un repositorio público llamado `lsfd-web`.
3. Sube TODOS los archivos de esta carpeta manteniendo la carpeta `assets`.
4. Ve a Settings → Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Branch: `main` y carpeta `/ (root)`.
7. Guarda y espera unos minutos.
8. GitHub te dará una dirección tipo: `https://TU-USUARIO.github.io/lsfd-web/`

## Conectar Jotform y Discord
Abre `script.js` y reemplaza:
- JOTFORM_URL por el enlace de tu formulario.
- DISCORD_URL por la invitación de tu servidor.

No necesitas pagar hosting.
